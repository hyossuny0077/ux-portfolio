# UI/UX Portfolio

개인 UI/UX 포트폴리오 사이트. GitHub Pages로 배포합니다.

빌드 도구 없는 순수 HTML/CSS/JS 정적 사이트입니다.

- `index.html` — 랜딩 페이지
- `project.html` — 대표 프로젝트 케이스 스터디
- `styles.css` — 공통 스타일
- `script.js` — 네비게이션 토글 등 최소 인터랙션

실제 이름·연락처·스크린샷은 `[이름을 입력하세요]`, `[이메일 주소]`, `[스크린샷: ...]` 같은 자리표시(placeholder)로 남겨 두었습니다. 직접 채워 넣은 뒤 배포하세요.
